    pd.DataFrame
        Input DataFrame with 'corrected_p_value' column added.

    Implements a two-stage testing procedure appropriate for dose-response data where only high doses are expected to be active:

    • Stage 1: Use minimum p-value within each group defined by hierarchical_by, then apply BH correction at the group level. A group passes if any member is significant.
    • Stage 2: For groups that pass Stage 1, apply BH correction to the individual tests within each group.

    Parameters:

    • map_scores (DataFrame) –

      DataFrame containing mAP scores with a 'p_value' column.

    • hierarchical_by (list) –

      Metadata column(s) defining the group structure (e.g., ['compound']).

    • sameby (list) –

      Metadata column(s) used for mAP calculation (e.g., ['compound', 'dose']).

    Returns:

    • DataFrame –

      Input DataFrame with additional columns: - corrected_p_value: BH-corrected p-value (1.0 for groups that didn't pass Stage 1). - stage1_p_value: Group-level p-value from Stage 1 (minimum p-value). - stage1_corrected_p_value: BH-corrected Stage 1 p-value. - stage1_significant: Whether the group passed Stage 1.

    Raises:

    • ValueError –

      If hierarchical_by is not a proper subset of sameby.

    Notes

    This method uses minimum p-value (rather than Simes) for Stage 1 aggregation. Min-p is appropriate for dose-response data where only high doses are expected to be active. Simes would penalize compounds for having inactive low doses, which is the expected biological behavior.

    def apply_hierarchical_fdr_correction(
    map_scores: pd.DataFrame,
    hierarchical_by: List[str],
    sameby: List[str],
) -> pd.DataFrame:
    """Apply hierarchical FDR correction for grouped hypotheses.

    Implements a two-stage testing procedure appropriate for dose-response data
    where only high doses are expected to be active:

    - Stage 1: Use minimum p-value within each group defined by `hierarchical_by`,
      then apply BH correction at the group level. A group passes if any member
      is significant.
    - Stage 2: For groups that pass Stage 1, apply BH correction to the
      individual tests within each group.

    Parameters
    ----------
    map_scores : pd.DataFrame
        DataFrame containing mAP scores with a 'p_value' column.
    hierarchical_by : list
        Metadata column(s) defining the group structure (e.g., ['compound']).
    sameby : list
        Metadata column(s) used for mAP calculation (e.g., ['compound', 'dose']).

    Returns
    -------
    pd.DataFrame
        Input DataFrame with additional columns:
        - `corrected_p_value`: BH-corrected p-value (1.0 for groups that didn't pass Stage 1).
        - `stage1_p_value`: Group-level p-value from Stage 1 (minimum p-value).
        - `stage1_corrected_p_value`: BH-corrected Stage 1 p-value.
        - `stage1_significant`: Whether the group passed Stage 1.

    Raises
    ------
    ValueError
        If `hierarchical_by` is not a proper subset of `sameby`.

    Notes
    -----
    This method uses minimum p-value (rather than Simes) for Stage 1 aggregation.
    Min-p is appropriate for dose-response data where only high doses are expected
    to be active. Simes would penalize compounds for having inactive low doses,
    which is the expected biological behavior.

    """
    sameby = check_group_columns(sameby, "sameby", map_scores)
    hierarchical_by = check_group_columns(hierarchical_by, "hierarchical_by")
    check_hierarchical_by(hierarchical_by, sameby)

    logger.info("Applying hierarchical FDR correction...")
    map_scores = map_scores.copy()

    # Stage 1: Aggregate p-values to group level using minimum p-value
    # Min-p is appropriate for dose-response where only high doses are expected to be active
    stage1_pvals = map_scores.groupby(hierarchical_by, observed=True).agg(
        {"p_value": "min"}
    )
    stage1_pvals.columns = ["stage1_p_value"]

    # Apply BH correction at the group level
    reject_stage1, stage1_corrected, _, _ = _multipletests(
        stage1_pvals["stage1_p_value"], method="fdr_bh"
    )
    stage1_pvals["stage1_corrected_p_value"] = stage1_corrected
    stage1_pvals["stage1_significant"] = reject_stage1

    # Merge Stage 1 results back to map_scores
    map_scores = map_scores.merge(
        stage1_pvals.reset_index(), on=hierarchical_by, how="left"
    )

    # Stage 2: For groups that passed Stage 1, apply BH within each group
    # For groups that didn't pass, set corrected_p_value to 1.0
    map_scores["corrected_p_value"] = np.where(
        map_scores["p_value"].notna(), 1.0, np.nan
    )

    for group_key, group_df in map_scores.groupby(hierarchical_by, observed=True):
        passed = group_df["stage1_significant"].iloc[0]
        if pd.isna(passed) or not passed:
            # Group didn't pass Stage 1, skip
            continue

        group_indices = group_df.index
        group_pvals = group_df["p_value"].values

        if len(group_pvals) == 1:
            # Single test in group, no additional correction needed
            map_scores.loc[group_indices, "corrected_p_value"] = group_pvals[0]
        else:
            # Apply BH correction within the group
            _, group_corrected, _, _ = _multipletests(group_pvals, method="fdr_bh")
            map_scores.loc[group_indices, "corrected_p_value"] = group_corrected

    return map_scores

    get_map_pvalue(ap_scores, sameby, null_size, seed=0, progress_bar=True, max_workers=None, cache_dir=None, pos_pairs=None, null='permutation', pairs=None, *, max_reference_profiles=16384, pool_memory_budget=4 * 1024 ** 3, key_table_memory_budget=256 * 1024 ** 2) ¶

    Compute mAP scores and p-values from AP scores.

    This function groups AP scores by the specified columns, computes the mean Average Precision (mAP) for each group, and calculates p-values by comparing against the null distribution of the group's mAP chosen by null. A null mAP counts against the group when it is >= the group's mAP, so an mAP equal to an atom of the null (e.g. perfect retrieval) counts the atom; values within the scores' rounding count as ties (copairs.nulls.tie_thresholds).

    Parameters:

    • ap_scores (DataFrame) –

      DataFrame containing individual Average Precision (AP) scores and pair statistics (e.g., number of positive pairs n_pos_pairs and total pairs n_total_pairs).

    • sameby (list or str) –

      Nonempty, distinct string column names present in the input.

    • null_size (int) –

      Number of Monte Carlo draws. Zero requests scores only: p-values are NaN after input/layout validation, without sampling or null-only tables.

    • seed (int or None, default: 0 ) –

      Reproducible seed; None resolves fresh entropy once per run. Joint and permutation accept integers in [0, 2**64); copied accepts any integer >= 0.

    • progress_bar (bool, default: True ) –

      Whether or not to show tqdm's progress bar.

    • max_workers (int, default: None ) –

      Threads that compute the copied null's p-values or run the permutation null's groups. Default defined by concurrent.futures.ThreadPoolExecutor.

    • cache_dir (str or Path, default: None ) –

      Location to save the cache of the copied null's AP samples.

    • pos_pairs (ndarray, default: None ) –

      The (n_pairs, 2) positive pairs used to compute the AP scores, indexing the rows of the frame average_precision returned (its return_pairs=True gives them, as pairs["pos"]); ap_scores must keep that frame's index. Pairs whose counts disagree with n_pos_pairs raise. When omitted, they are taken from pairs or, failing that, from the pairs average_precision attached to ap_scores. Multi-member groups require actual positive pairs; counts alone do not identify their graph. Singletons can use their AP null without pairs. If a pair handle is available, explicit positive pairs must agree with it. Joint null only.

    • null (str, default: 'permutation' ) –

      Null of the group mAP. "permutation" (default) relabels profiles (copairs.nulls.permutation): in each block of members ranked against the same references (e.g. a plate's replicates and controls), any of the block's profiles could have carried the group's label, and each draw recomputes the group's mAP from the observed similarities. All positive edges must stay inside the tested group; the graph need not be complete. Original metadata rules define the graph and reference pools and are not reapplied per draw. A singleton with external positives can use "joint", its AP null. Positive draw counts use Monte Carlo sampling with (hits + 1)/(draws + 1). It recomputes similarities, so APs computed with a distance that estimates its scale per batch ("seuclidean", "mahalanobis") raise. Multilabel pair dictionaries use negative-graph components, preserving member counts per component and other labels, with the original positive graph. Negatives follow the original negative/lone-pair structure; counts can change. Each group must contain one complete label. Overlapping reference sets are allowed for this explicitly distinct multilabel model. "joint" samples the members' APs together (copairs.nulls.joint): a positive pair inside the group is one random number in both members' rank lists, and other similarities are independent, which real profiles are not (members share references, and some profiles are close to many others), so it can give too small p-values for groups of many replicates. "copied" samples each member's AP null per (n_pos_pairs, n_total_pairs) configuration and the group's null averages them, so members with equal pair counts share one draw and the null does not narrow as replicates are added.

    • pairs (dict, default: None ) –

      Dictionary with "pos", "neg" and "similarity" entries, as average_precision(..., return_pairs=True) returns them; their indices are rows of that call's frame, so ap_scores must keep its index. The permutation null needs them and, when not given, takes them from ap_scores.attrs["copairs_pairs"], where average_precision attaches them; frames that lost them (built, reloaded, pickled, or concatenated from several AP calls) need pairs= or another null. The joint null takes its positive pairs from pairs too, or from the attached pairs (see pos_pairs). Multilabel dictionaries also carry "label_col", "profile", "row_key", "keys" and the lazy "_lone" pair function; "label_col" selects the multilabel permutation path. Explicit pairs override attachments. Keep the original index, matching pairs and complete tested groups/labels; validation checks structure, not source identity or group completeness. Recompute AP when removing group members. Copies share the dictionary, features and arrays; keep them unchanged between AP and mAP. Custom similarities must return the same value for a pair regardless of batch size or contents.

    • max_reference_profiles (int, default: 16384 ) –

      Maximum total reference profiles across a tested group's blocks; >= 0. For multilabel groups, component-union size minus its members; all components count. Pool-table estimates include members too. Checked before quadratic pool tables are allocated.

    • pool_memory_budget (int, default: 4294967296 ) –

      Positive byte budget for estimated concurrent pool key/rank tables. One oversized pool may run alone. This does not cap total process RAM.

    • key_table_memory_budget (int, default: 268435456 ) –

      Byte limit for optional cross-pool key reuse; zero disables it. Neither budget includes features, layouts or all temporary arrays.

    Returns:

    • DataFrame –

      DataFrame with the following columns: - Columns from sameby (group identifiers). - mean_average_precision: Mean AP score for each group. - mean_normalized_average_precision: Mean normalized AP score (scale-independent). - p_value: p-value comparing mAP to the null distribution. - indices: The group's rows, as positions in ap_scores after rows with a NaN AP or no positive pairs are dropped.

    Raises:

    • UnpairedException –

      If no row has a non-NaN AP, positive pairs and a value in every sameby column, e.g. an empty table.

    • ValueError –

      Invalid grouping, pair dictionaries/counts, layout or resource arguments. max_workers must be a positive integer or None even for zero draws and joint sampling, which does not use that executor.

    def get_map_pvalue(
    ap_scores: pd.DataFrame,
    sameby: List[str],
    null_size: int,
    seed: int | None = 0,
    progress_bar: bool = True,
    max_workers: Optional[int] = None,
    cache_dir: Optional[Union[str, Path]] = None,
    pos_pairs: Optional[np.ndarray] = None,
    null: str = "permutation",
    pairs: dict | None = None,
    *,
    max_reference_profiles: int = 16_384,
    pool_memory_budget: int = 4 * 1024**3,
    key_table_memory_budget: int = 256 * 1024**2,
) -> pd.DataFrame:
    """Compute mAP scores and p-values from AP scores.

    This function groups AP scores by the specified columns, computes the mean
    Average Precision (mAP) for each group, and calculates p-values by comparing
    against the null distribution of the group's mAP chosen by `null`. A null
    mAP counts against the group when it is ``>=`` the group's mAP, so an mAP
    equal to an atom of the null (e.g. perfect retrieval) counts the atom; values
    within the scores' rounding count as ties (`copairs.nulls.tie_thresholds`).

    Parameters
    ----------
    ap_scores : pd.DataFrame
        DataFrame containing individual Average Precision (AP) scores and pair statistics
        (e.g., number of positive pairs `n_pos_pairs` and total pairs `n_total_pairs`).
    sameby : list or str
        Nonempty, distinct string column names present in the input.
    null_size : int
        Number of Monte Carlo draws. Zero requests scores only: p-values are NaN
        after input/layout validation, without sampling or null-only tables.
    seed : int or None, default 0
        Reproducible seed; None resolves fresh entropy once per run. Joint and
        permutation accept integers in [0, 2**64); copied accepts any integer >= 0.
    progress_bar : bool
        Whether or not to show tqdm's progress bar.
    max_workers : int
        Threads that compute the copied null's p-values or run the
        permutation null's groups. Default defined by
        `concurrent.futures.ThreadPoolExecutor`.
    cache_dir : str or Path
        Location to save the cache of the copied null's AP samples.
    pos_pairs : np.ndarray, optional
        The `(n_pairs, 2)` positive pairs used to compute the AP scores,
        indexing the rows of the frame `average_precision` returned (its
        `return_pairs=True` gives them, as `pairs["pos"]`); `ap_scores` must keep
        that frame's index. Pairs whose counts disagree with `n_pos_pairs`
        raise. When omitted, they are taken from ``pairs`` or, failing that,
        from the pairs `average_precision` attached to ``ap_scores``. Multi-member
        groups require actual positive pairs; counts alone do not identify their
        graph. Singletons can use their AP null without pairs. If a pair handle
        is available, explicit positive pairs must agree with it. Joint null only.
    null : str
        Null of the group mAP. ``"permutation"`` (default) relabels profiles
        (`copairs.nulls.permutation`): in each block of members ranked against
        the same references (e.g. a plate's replicates and controls), any of
        the block's profiles could have carried the group's label, and each
        draw recomputes the group's mAP from the observed similarities. All
        positive edges must stay inside the tested group; the graph need not
        be complete. Original metadata rules define the graph and reference
        pools and are not reapplied per draw. A singleton with external
        positives can use ``"joint"``, its AP null. Positive draw counts use
        Monte Carlo sampling with (hits + 1)/(draws + 1). It recomputes similarities, so
        APs computed with a distance that estimates its scale per batch
        (``"seuclidean"``, ``"mahalanobis"``) raise. Multilabel pair dictionaries
        use negative-graph components, preserving member counts per component
        and other labels, with the original positive graph. Negatives follow
        the original negative/lone-pair structure; counts can change. Each
        group must contain one complete label. Overlapping reference sets are
        allowed for this explicitly distinct multilabel model. ``"joint"`` samples
        the members' APs together (`copairs.nulls.joint`): a positive pair
        inside the group is one random number in both members' rank lists,
        and other similarities are independent, which real profiles are not
        (members share references, and some profiles are close to many
        others), so it can give too small p-values for groups of many
        replicates. ``"copied"`` samples each member's AP null per
        `(n_pos_pairs, n_total_pairs)`
        configuration and the group's null averages them, so members with
        equal pair counts share one draw and the null does not narrow as
        replicates are added.
    pairs : dict, optional
        Dictionary with ``"pos"``, ``"neg"`` and ``"similarity"`` entries, as
        ``average_precision(..., return_pairs=True)`` returns them; their
        indices are rows of that call's frame, so ``ap_scores`` must keep its
        index. The permutation null needs them and, when not given, takes
        them from ``ap_scores.attrs["copairs_pairs"]``, where
        `average_precision` attaches them; frames that lost them (built,
        reloaded, pickled, or concatenated from several AP calls) need
        ``pairs=`` or another null. The joint null takes its positive pairs
        from ``pairs`` too, or from the attached pairs (see ``pos_pairs``).
        Multilabel dictionaries also carry ``"label_col"``, ``"profile"``,
        ``"row_key"``, ``"keys"`` and the lazy ``"_lone"`` pair function;
        ``"label_col"`` selects the multilabel permutation path.
        Explicit pairs override attachments. Keep the original index, matching
        pairs and complete tested groups/labels; validation checks structure,
        not source identity or group completeness. Recompute AP when removing
        group members. Copies share the dictionary, features and arrays; keep
        them unchanged between AP and mAP. Custom similarities must return the
        same value for a pair regardless of batch size or contents.
    max_reference_profiles : int, default 16384
        Maximum total reference profiles across a tested group's blocks; >= 0.
        For multilabel groups, component-union size minus its members; all
        components count. Pool-table estimates include members too.
        Checked before quadratic pool tables are allocated.
    pool_memory_budget : int, default 4294967296
        Positive byte budget for estimated concurrent pool key/rank tables.
        One oversized pool may run alone. This does not cap total process RAM.
    key_table_memory_budget : int, default 268435456
        Byte limit for optional cross-pool key reuse; zero disables it.
        Neither budget includes features, layouts or all temporary arrays.

    Returns
    -------
    pd.DataFrame
        DataFrame with the following columns:
        - Columns from `sameby` (group identifiers).
        - `mean_average_precision`: Mean AP score for each group.
        - `mean_normalized_average_precision`: Mean normalized AP score (scale-independent).
        - `p_value`: p-value comparing mAP to the null distribution.
        - `indices`: The group's rows, as positions in ap_scores after rows
          with a NaN AP or no positive pairs are dropped.

    Raises
    ------
    UnpairedException
        If no row has a non-NaN AP, positive pairs and a value in every
        `sameby` column, e.g. an empty table.
    ValueError
        Invalid grouping, pair dictionaries/counts, layout or resource arguments.
        ``max_workers`` must be a positive integer or None even for zero draws
        and joint sampling, which does not use that executor.

    """
    null = check_null(null)
    null_size = check_null_size(null_size)
    sameby = check_group_columns(sameby, "sameby", ap_scores)
    max_workers = check_max_workers(max_workers)
    resources = dict(
        zip(
            ("max_reference_profiles", "pool_memory_budget", "key_table_memory_budget"),
            permutation.check_resources(
                max_reference_profiles, pool_memory_budget, key_table_memory_budget
            ),
        )
    )
    if null != "copied":
        check_seed(seed)
    elif seed is not None and (int(seed) != seed or seed < 0):  # NumPy: any int >= 0
        raise ValueError(f"seed must be a non-negative integer, got {seed}")
    if null != "joint" and pos_pairs is not None:
        raise ValueError("pos_pairs is used by the joint null only")
    if null != "copied" and pairs is None:
        pairs = attached_pairs(ap_scores)
    if pairs is not None and null != "copied":
        if (
            not isinstance(pairs, dict)
            or not {"pos", "neg", "similarity"} <= pairs.keys()
        ):
            raise ValueError(
                "pairs must be a dictionary with pos, neg and similarity entries"
            )
        if pos_pairs is not None and not np.array_equal(
            check_pairs(pos_pairs, "pos_pairs"),
            check_pairs(pairs["pos"], "positive pairs"),
        ):
            raise ValueError(
                "pos_pairs must index the rows of the AP frame and match the selected handle's positive pairs"
            )
    if null == "joint" and pos_pairs is None and pairs is not None:
        pos_pairs = pairs["pos"]

        progress_bar=progress_bar,
    )  # fmt: skip

    def build_rank_lists(
    pos_pairs: np.ndarray,
    neg_pairs: np.ndarray,
    pos_sims: np.ndarray,
    neg_sims: np.ndarray,
):
    """Build rank lists for calculating average precision.

    This function processes positive and negative pairs along with their similarity scores
    to construct rank lists and determine unique profile indices with their associated counts.

    Parameters
    ----------
    pos_pairs : np.ndarray
        Array of positive pair indices, where each pair is represented as a pair of integers.

    neg_pairs : np.ndarray
        Array of negative pair indices, where each pair is represented as a pair of integers.

    pos_sims : np.ndarray
        Array of similarity scores for positive pairs.

    neg_sims : np.ndarray
        Array of similarity scores for negative pairs.

    Returns
    -------
    paired_ix : np.ndarray
        Unique indices of profiles that appear in the rank lists.

    rel_k_list : np.ndarray
        Array of relevance labels (1 for positive pairs, 0 for negative pairs) sorted by
        decreasing similarity within each profile.

    counts : np.ndarray
        Array of counts indicating how many times each profile index appears in the rank lists.
    """
    # Combine relevance labels: 1 for positive pairs, 0 for negative pairs
    labels = np.concatenate(
        [
            np.ones(pos_pairs.size, dtype=np.uint32),
            np.zeros(neg_pairs.size, dtype=np.uint32),
        ]
    )

    # Flatten positive and negative pair indices for ranking
    ix = np.concatenate([pos_pairs.ravel(), neg_pairs.ravel()])

    # Expand similarity scores to match the flattened pair indices
    sim_all = np.concatenate([np.repeat(pos_sims, 2), np.repeat(neg_sims, 2)])

    # Sort by index (lexicographical order) and then by similarity (descending)
    # `1 - sim_all` ensures higher similarity values appear first, prioritizing
    # pairs with stronger similarity scores for ranking.
    # `ix` acts as a secondary criterion, ensuring consistent ordering of pairs
    # with equal similarity scores by their indices (lexicographical order).
    ix_sort = np.lexsort([1 - sim_all, ix])

    # Create the rank list of relevance labels sorted by similarity and index
    rel_k_list = labels[ix_sort]

    # Find unique profile indices and count their occurrences in the pairs
    paired_ix, counts = np.unique(ix, return_counts=True)

    return paired_ix, rel_k_list, counts.astype(np.uint32)

    Implements a two-stage testing procedure appropriate for dose-response data
    where only high doses are expected to be active:

        - `stage1_corrected_p_value`: BH-corrected Stage 1 p-value.
        - `stage1_significant`: Whether the group passed Stage 1.

    Raises
    ------
    ValueError
        If `hierarchical_by` is not a proper subset of `sameby`.

    Notes
    -----
    This method uses minimum p-value (rather than Simes) for Stage 1 aggregation.
    Min-p is appropriate for dose-response data where only high doses are expected
    to be active. Simes would penalize compounds for having inactive low doses,
    which is the expected biological behavior.

    """
    sameby = check_group_columns(sameby, "sameby", map_scores)
    hierarchical_by = check_group_columns(hierarchical_by, "hierarchical_by")
    check_hierarchical_by(hierarchical_by, sameby)

    logger.info("Applying hierarchical FDR correction...")
    map_scores = map_scores.copy()

    # Stage 1: Aggregate p-values to group level using minimum p-value
    # Min-p is appropriate for dose-response where only high doses are expected to be active
    stage1_pvals = map_scores.groupby(hierarchical_by, observed=True).agg(
        {"p_value": "min"}
    )
    stage1_pvals.columns = ["stage1_p_value"]

    # Apply BH correction at the group level
    reject_stage1, stage1_corrected, _, _ = _multipletests(
        stage1_pvals["stage1_p_value"], method="fdr_bh"
    )
    stage1_pvals["stage1_corrected_p_value"] = stage1_corrected
    stage1_pvals["stage1_significant"] = reject_stage1

    # Merge Stage 1 results back to map_scores
    map_scores = map_scores.merge(
        stage1_pvals.reset_index(), on=hierarchical_by, how="left"
    )

    # Stage 2: For groups that passed Stage 1, apply BH within each group
    # For groups that didn't pass, set corrected_p_value to 1.0
    map_scores["corrected_p_value"] = np.where(
        map_scores["p_value"].notna(), 1.0, np.nan
    )

    for group_key, group_df in map_scores.groupby(hierarchical_by, observed=True):
        passed = group_df["stage1_significant"].iloc[0]
        if pd.isna(passed) or not passed:
            # Group didn't pass Stage 1, skip
            continue

        group_indices = group_df.index
        group_pvals = group_df["p_value"].values

        if len(group_pvals) == 1:
            # Single test in group, no additional correction needed
            map_scores.loc[group_indices, "corrected_p_value"] = group_pvals[0]
        else:
            # Apply BH correction within the group
            _, group_corrected, _, _ = _multipletests(group_pvals, method="fdr_bh")
            map_scores.loc[group_indices, "corrected_p_value"] = group_corrected

    return map_scores

        draw recomputes the group's mAP from the observed similarities. All

        positives can use ``"joint"``, its AP null. Positive draw counts use

    def expected_ap(M: int, N: int) -> float:
    """Compute the expected Average Precision under random ranking.

    This implements the exact finite-sample formula for expected AP when
    items are randomly ranked.

    Parameters
    ----------
    M : int
        Number of positive items (relevant documents).
    N : int
        Number of negative items (irrelevant documents).

    Returns
    -------
    float
        The expected Average Precision under random ranking.

    Notes
    -----
    Formula: E[AP] = (1/L) × [(M-1)/(L-1) × (L - H_L) + H_L]
    where L = M + N and H_L is the L-th harmonic number.
    """
    L = M + N

    # Handle edge cases
    if L < 1 or M < 0 or N < 0:
        raise ValueError(f"Invalid inputs: M={M}, N={N}")
    if L == 1:
        return 1.0 if M == 1 else 0.0
    if M == 0:
        return 0.0
    if M == L:  # All items are positive
        return 1.0

    # Compute the L-th harmonic number
    H_L = harmonic_number(L)

    # Apply the exact formula
    mu0 = (1.0 / L) * (((M - 1.0) / (L - 1.0)) * (L - H_L) + H_L)

    return mu0

    def normalize_ap(
    ap: Union[float, np.ndarray],
    M: Union[int, np.ndarray],
    N: Union[int, np.ndarray],
    eps: float = 1e-10,
) -> Union[float, np.ndarray]:
    """Normalize Average Precision scores to be scale-independent.

    Computes the normalized AP as (AP - μ₀) / (1 - μ₀) where μ₀ is the
    expected AP under random ranking.

    Parameters
    ----------
    ap : float or np.ndarray
        The Average Precision score(s) to normalize.
    M : int or np.ndarray
        Number of positive items for each AP score.
    N : int or np.ndarray
        Number of negative items for each AP score.
    eps : float
        Small epsilon to avoid division by zero when μ₀ ≈ 1.

    Returns
    -------
    float or np.ndarray
        The normalized Average Precision score(s).

    Notes
    -----
    - Normalized AP = 0 when performance equals random chance
    - Normalized AP = 1 when performance is perfect
    - Negative values indicate worse-than-random performance
    """
    # Handle scalar or array inputs
    is_scalar = np.isscalar(ap)

    ap = np.atleast_1d(ap)
    M = np.atleast_1d(M)
    N = np.atleast_1d(N)

    # Validate that all arrays have compatible lengths
    lengths = [
        len(ap),
        len(M) if len(M) > 1 else len(ap),
        len(N) if len(N) > 1 else len(ap),
    ]
    if len(set(lengths)) > 1:
        raise ValueError(
            f"Array lengths must match: ap={len(ap)}, M={len(M)}, N={len(N)}"
        )

    # Compute expected AP for each configuration
    mu0 = np.zeros_like(ap, dtype=float)
    for i in range(len(ap)):
        M_i = M[i] if len(M) > 1 else M[0]
        N_i = N[i] if len(N) > 1 else N[0]
        mu0[i] = expected_ap(int(M_i), int(N_i))

    # Normalize: (AP - μ₀) / (1 - μ₀)
    # Use eps to avoid division by zero when μ₀ ≈ 1
    denominator = np.maximum(1 - mu0, eps)
    normalized = (ap - mu0) / denominator

    # Clip to [-1, 1] range to handle numerical edge cases
    normalized = np.clip(normalized, -1.0, 1.0)

    return float(normalized[0]) if is_scalar else normalized
